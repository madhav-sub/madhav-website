# Madhav — Personal website

An independent home for engineering work and investigations into abstraction, intelligence, information, and complex systems.

## Run locally

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy to Vercel

1. Push this project to the `madhav-sub/madhav-website` GitHub repository.
2. At https://vercel.com/new, import the GitHub repository.
3. Keep the detected Next.js defaults and click Deploy.

This first version is a static Next.js site; no credentials, database, or paid API services are required.
